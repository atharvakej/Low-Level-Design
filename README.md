# OOPs in Python

## 📚 Object-Oriented Programming Tutorial

Welcome to your hands-on OOP Python tutorial! This repository contains step-by-step lessons to master Object-Oriented Programming concepts.

## 🎯 Learning Path

1. **Basics** - Classes and Objects
2. **Constructor** - The `__init__` method
3. **Attributes** - Instance and Class attributes
4. **Methods** - Instance, Class, and Static methods
5. **Encapsulation** - Public, Protected, and Private members
6. **Inheritance** - Single and Multiple inheritance
7. **Polymorphism** - Method overriding and overloading
8. **Abstraction** - Abstract classes and interfaces
9. **Magic Methods** - Special methods like `__str__`, `__repr__`, etc.
10. **Real Project** - Building a complete application using OOP

## 🚀 How to Use This Tutorial

1. Each lesson is in a separate Python file
2. Read the comments and explanations
3. Run the code to see the output
4. Complete the exercises at the end of each file
5. Experiment by modifying the code!

## 📂 Files Structure

- `01_classes_objects.py` - Introduction to classes and objects
- `02_constructor.py` - Understanding the __init__ method
- `03_attributes.py` - Working with attributes
- `04_methods.py` - Different types of methods
- `05_encapsulation.py` - Data hiding and access control
- `06_inheritance.py` - Code reusability through inheritance
- `07_polymorphism.py` - One interface, multiple implementations
- `08_abstraction.py` - Abstract classes and methods
- `09_magic_methods.py` - Special Python methods
- `10_project.py` - Final project: Library Management System

Let's start with Lesson 1! 🎉
